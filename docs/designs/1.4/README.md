# Ch 1.4 designs: Comic Vine search, the series page, the issue page, the contents picker

Four screens, drawn in the Nookkeeper's seat before the spec (House Rules step 0), onto the pages as built at `dev` `920109b`, not onto the 1.3 drawings. The canvas is https://claude.ai/artifact/BXAPvwiszmTKCsf7VE2Phz (private); these exports are what the team builds to. Every color, size and word comes from `docs/designs/deep-field/` and the 1.2 and 1.3 screens; nothing new was invented for the look. The exports were rendered at 1280 wide with the real fonts; the dashed "no cover" boxes stand where Comic Vine's images go, since none were copied.

The import sheet (Add on a series row) is not drawn: it is the 1.2 match sheet with the Comic Vine side, a "What are these?" radio (Single issues / Collected editions with a Format select) and, on a match, the catalog side with Same / Different; section 0's A8 is its spec.

As built (Ch 1.4 Afterword): `search-comics.png`'s fourth status line ("Comic Vine lists a collection as a series of volumes") was replaced by the match line the collected rule gives ("Looks like one you have: 5 collected editions added by hand"), and the comics heading stays under the Comics chip as drawn (1.4.1 D3). `series.png`'s "Ongoing" isn't printed (a series' kind is null until something sets it), the tiles read the held titles ("The Great Chase", not "Teenage Mutant Ninja Turtles #3"), and the lede reads "Vol. 1. Volume 1." with Comic Vine's deck after the volume (1.4.2 D2; a Deferral when the deck only repeats). `item-issue.png`'s Creators fact is not built (credits are a detail call per issue; Deferral) and the shelf pill reads the fixture's "TMNT, the Mirage run". `item-collected-contents.png`'s subtitle doesn't pretick from the description (Deferral) and the one-shot's row reads "Raphael: Me, Myself and I" in full; Save keeps a held comic's place in the printing (1.4.3 D3). The import sheet was built as A8 specifies, with the picked-group select for a run Comic Vine names differently.

Phone width is not drawn: the screens follow 1.2's rules (the chip rail wraps under the box, the series grid drops to two across, the sheet's two sides stack, the picker fills the width).
