# Ch 1.5 designs: the nook, the shelf page, the three doors

Five screens, drawn in the Nookkeeper's seat before the spec (House Rules step 0), onto the pages as built at `dev` `b619a75`. The canvas is https://claude.ai/artifact/XmoTW7eSK7LRwtezFLhsa7 (private); these exports are what the team builds to. Every color, size and word comes from `docs/designs/deep-field/` and the 1.2 to 1.4 screens; the one new piece of furniture is the grip (six dots, an inline SVG inside a 44×44 `button`), the first icon on any screen, kept because "Reorder" as a word on 326 rows is noise. The exports were rendered at 1280 wide with the real fonts; the dashed "no cover" and "no poster" boxes stand where covers go, since the fixtures carry none.
