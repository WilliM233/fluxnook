### Step 1: The contents line, one formatter for three places
- Does: Writes `contentsLine` in `src/lib/catalog/contents-line.ts`, the pure function that prints an edition's contents as A10's Contents line, A9's Collected in row and the issue page's "with ..." row, unit-tested on the fixture's five editions.
- Touches: `src/lib/catalog/contents-line.ts` (new; no database import, so the picker's client component can print the same line), `tests/unit/contents-line.test.ts` (new).
- How: `ContentRow = { itemId, title, number: number | null, series: string | null, seriesId: string | null, position }`. `contentsLine(rows, { own?, omit? })`: drop the `omit` item; the own group is the rows whose `seriesId` equals `own.seriesId` when one is given, else whose `series` text equals `own.series` when one is given; every other row with a series text groups by that text in order of first position; rows with none are "the rest" in position order. A group's numbered rows sort by number and print as runs: two or more consecutive numbers "#a to #b", a lone one "#a", runs joined with ", "; its unnumbered rows follow by title. The own group prints its runs alone; another series group prints "<series text> <runs>"; the rest print their titles. With `own`, the line is "<own runs>, and <the others joined with ', '>" (", and " only when both halves exist); without `own`, every group joins with ", ". With `omit`, a non-empty line starts "with ". Empty → "" (the callers print "Nothing yet" or their section's sentence). The decisions, since the spec gives the words and not the joins: the own group first because the page is about it; others by first position because that is the edition's own order; the series text (not the `series` row's name) because C6 fixed the Contents line on it and a Different-imported run has no hand label.
- Observable: `npm test -- tests/unit/contents-line.test.ts` green with the cases below.
- Tests: UC1's eight rows, no own → "Teenage Mutant Ninja Turtles (Mirage) Vol. 1 #1 to #7, Raphael: Me, Myself and I"; UC1 with own `{ series: "Teenage Mutant Ninja Turtles (Mirage) Vol. 1" }` → "#1 to #7, and Raphael: Me, Myself and I"; the same with `omit` #1 → "with #2 to #7, and Raphael: Me, Myself and I"; UC1 with own by `seriesId` (the eight rows carrying a seriesId on the seven) → the same as by text; UC2 with own → "#8 to #11, and Michelangelo: The Christmas Aliens, Donatello: Kirby and the Warp Crystal, Leonardo: What Goes Around... ...Comes Around!"
