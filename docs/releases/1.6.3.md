# 1.6.3: The journal and the shelf

Everything you have written now has a page, and the shelf knows what you thought.

- Journal, in the header, lists every entry you have written across every work, newest first, under a label for each day. Each row shows the work, where the read stands ("Reading since 28 October", "Done, 9 March 2019 · ★ 4.5"), what you wrote, its page or chapter, and the time. Edit and Delete work right there.
- Past 50 entries, Older entries takes you to the next page.
- A shelf shows a work's stars and "read twice" on its row, and its line ends with the mean of the works that have stars: "11 works · 1 done · ★ 4.8 from 2 rated". Each section's line has its own.
- Mark a work Done on a shelf and it asks "Read it?" (or "Watched it?"). Log a read opens the sheet with Done picked and today as the day; Not now puts Remove back. Done still writes nothing on its own.

**Under the floorboards.** No new route, migration or dependency. `/journal` is a server page (`src/app/(app)/journal/page.tsx`) that computes every string and a client island (`journal-rows.tsx`) for Edit and Delete through 1.6.2's sheets. `src/lib/journal/journal-page.ts` reads the totals and a page of 51 rows (50 shown) by keyset on `(written_at, id)`; `cursor.ts` parses `?before=<written_at>,<id>` and refuses anything that is not a real UTC instant with microseconds and a uuid, which is a 404 inside the shell. `loadShelfPage` gains two correlated subqueries per row, scoped by `s.owner`: the latest starred read's stars (the order of `sortReads` and `latestStarred`, in SQL) and the read count. `meanStars` in `stars.ts` works in doubled integers and rounds half up on the exact mean (4.75 is 4.8). `countsLine` takes an optional `rated`; the nook's cards pass none and print as before. The offer is view state in `shelf-view.tsx` and shows only after a Done the server answered 200. 1.6.2's two fired Deferrals are closed: `src/components/ui/text-button.tsx` and `src/lib/api/request.ts` replace the copies of the text button and `json`, and `journal-owner.test.ts` loads before it looks. `scripts/browse/1.6.3.sh` is the chapter's exit Browse: 189 checks, 0 failed in the Binder's run, with one Playwright test run partway (the offer's 500). `npm test` is 803 tests in 82 files; the full `npm run test:e2e` before the Rummage fixes was 188 passed in one run. `package.json` is `0.1.0-ch.6.3`. The Raccoon found, and the chapter fixed: a `before` with a real shape and no real date (February 30th, month 13, year 0) answering a 500; an offer coming back on a row another tab had set to Unmarked; a pasted URL running out of an entry's row and out of the item page's card; a `before` page with nothing under it printing the whole journal's count over an empty list; Edit on an entry another tab had deleted leaving a row that could be edited again.

**Not yet.** The Journal page has no Newer link and no page count, only the header. Cancel on the offer's sheet leaves the offer standing; Not now dismisses it. Done on a work with a Reading read open offers a new read with Done picked and leaves the open one open. A Done read with a Started date and no Finished prints "Done" on the Journal row with no date. A shelf's row stars come from your own reads by owner; showing a shelf to anyone else, and what that does to those stars, is Volume 2's. A work's Journal section past 50 reads, stars on the nook's shelf cards, and which printing a read was of (Chapter 1.7) wait for their triggers in the chapter plan's Deferrals.
