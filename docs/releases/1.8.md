# 1.8: Close-out

A sheet now stays put while it saves. On all eleven sheets that write something (Own a copy, the delete confirms, Log a read and Edit this read, the entry sheet, the four shelf sheets, the contents picker and the two import sheets), Cancel goes grey while the save is out, and Escape, a click outside and the × do nothing until it answers. The fields lock too, so a word typed while the save is out can't be lost when the sheet closes. In Add works the "Search the providers" link turns to plain words while a save is out, and the series import sheet says "Bringing the series in. A run of sixty issues takes a few seconds." while it works.

If a save is sent and its answer never comes back, Cancel now closes the sheet and, wherever the page shows what the sheet wrote, reads the page again, so what landed is what you see. Deleting a shelf that way takes you to the nook, where a good answer would have. Finishing a read from a shelf that way no longer leaves "Watched it?" on the row, so it can't log a second read. Edit contents, Edit shelf, Edit this read and Edit entry wait for the page to read again before they open, so a second edit starts from what the first saved. Two quick Backs past Search now land where they were aimed, where Search could come back over the page. And a long email address in the header no longer pushes a phone sideways.
